These nine `typescript-*` skills come from APIMatic's PayPal Context Plugin:
https://github.com/context-plugins/plugin-marketplace/tree/main/plugins/paypal/skills/typescript
(commit `7cbdf85dc95f09d9ede8c5d349506686684fa0d4`, MIT License, Copyright (c) 2026- APIMatic).

They were installed by copying from a clone of the marketplace repo (the `npx skills add` installer could not run in the
cloud build sandbox). The only change to the files: em dashes were replaced with hyphens to match this repo's writing
rule. See `paypal-plan.md` at the repo root for the plan and contract sheet these skills ask for, and the README section
"Sponsor tool: APIMatic" for how they were used.
