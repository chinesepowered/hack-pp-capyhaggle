How it was built

PayPal, sandbox

Money that waits for the handoff

  • Orders v2 with intent AUTHORIZE
  • Authorizations: capture, void, reauthorize
  • Payouts to the seller
  • Verified webhooks, and polling as a fallback
  • JS SDK v6 for the buyer's approval
  • Agent Toolkit: get_order, create_refund

One honest limitation

Sandbox demo. The marketplace account holds and settles the money. A real launch needs seller onboarding and identity checks.
